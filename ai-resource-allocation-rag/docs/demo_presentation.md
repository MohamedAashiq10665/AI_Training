# Demo Presentation Script

## 1. Opening (45 seconds)
Good morning.
Today I am presenting my capstone project: AI-Powered Resource Allocation and Bench Management with RAG.

The problem I focused on is that staffing decisions are often manual, slow, and hard to justify. Teams struggle to quickly find the right people, reduce bench time, and maintain utilization.

My solution is an end-to-end MVP that combines secure APIs, workforce analytics, and AI-based recommendation logic to help managers make faster and more explainable staffing decisions.

## 2. What I Built (1 minute)
The system has three main parts:

- Backend services for authentication, role-based access, employee analytics, and recommendations.
- Frontend dashboard for operational visibility and recommendation workflows.
- AI layer using retrieval-augmented generation and model benchmarking.

Key capabilities include:

- Login with JWT and role-based permissions.
- Workforce analytics such as bench percentage and utilization.
- Two operational tabs for Employees and Projects.
- AI recommendation engine for project-role matching.
- AI-driven fit candidates inside project details.
- Assign and unassign workflows for allocated resources.
- Cross-project AI recommendation chat for transfer suggestions.
- Explainability with matched skills and missing skills.
- Benchmark artifacts for comparing model behavior.
- Tests and documentation for production-style quality.

## 5. Architecture Explanation (2 minutes)
High-level architecture:

- Frontend sends authenticated requests.
- FastAPI backend validates token and role.
- Backend pulls employee and project signals from persistence.
- RAG pipeline retrieves relevant context candidates.
- Scoring logic computes fit using skills, experience, utilization, and availability.
- Project allocation APIs manage assignment and unassignment updates.
- Project AI chat augments decision-making for cross-project staffing.
- API returns explainable recommendation objects to UI.

Design choices:

- JWT + RBAC for security.
- Repository and service layering for maintainability.
- Explainability-first recommendation output.
- Benchmarking and tests for quality control.
